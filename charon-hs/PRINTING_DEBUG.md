# Printing Mechanism Debugging Guide

This guide explains how to use the interactive debugging utilities for the Charon printing mechanism.

## Interactive Testing with `stack ghci`

### Setup

1. Make sure you're in the `charon-hs` directory:
   ```bash
   cd charon-hs
   ```

2. Start the GHCi REPL:
   ```bash
   stack ghci
   ```

3. Load the debug module:
   ```haskell
   :load Charon.PrintingDebug
   ```

### Available Functions

#### `compareFile :: String -> IO ()`

Compare Haskell printing output with Rust's expected output for a test file.

**Usage:**
```haskell
compareFile "foreign-constant"
```

**Output:**
- Shows the first 30 lines of expected vs actual output
- Displays total line counts
- Helps identify formatting differences

**Example:**
```haskell
ghci> compareFile "foreign-constant"
=========================================
Comparison for: foreign-constant
=========================================

=== EXPECTED OUTPUT ===
// Full name: foreign_constant_aux::CONSTANT
pub fn CONSTANT() -> u8
= <opaque>

pub const CONSTANT: u8 = CONSTANT()
...

=== ACTUAL OUTPUT ===
// Full name: foreign_constant_aux::CONSTANT
pub fn CONSTANT() -> u8
= <opaque>
...
```

#### `printFile :: String -> IO ()`

Just print the Haskell output for a test file without comparison.

**Usage:**
```haskell
printFile "foreign-constant"
```

**Output:**
- Prints the full Haskell-generated output for the LLBC file

**Example:**
```haskell
ghci> printFile "unsafe-impl-send"
# Final LLBC before serialization:

struct Foo<T>
{
    x: T,
}
...
```

#### `showDiff :: String -> IO ()`

Show a detailed line-by-line diff between expected and actual output.

**Usage:**
```haskell
showDiff "foreign-constant"
```

**Output:**
- Line-by-line comparison
- `[OK]` for matching lines
- `[DIFF]` for differing lines with both versions shown

**Example:**
```haskell
ghci> showDiff "foreign-constant"
=========================================
Line-by-line diff for: foreign-constant
=========================================
[OK]   Line 1: // Full name: foreign_constant_aux::CONSTANT
[OK]   Line 2: pub fn CONSTANT() -> u8
[DIFF] Line 3:
  Expected: = <opaque>
  Actual:   =<opaque>

[OK]   Line 4: 
[OK]   Line 5: pub const CONSTANT: u8 = CONSTANT()
...
```

#### `loadAndPrint :: String -> IO (Maybe TranslatedCrate)`

Load an LLBC file and return the crate for custom processing.

**Usage:**
```haskell
maybeCrate <- loadAndPrint "foreign-constant"
case maybeCrate of
  Just crate -> do
    let ctx = emptyCtx { translated = Just crate }
    -- Now you can print specific declarations
    putStrLn $ printWithCtx ctx someDecl
  Nothing -> putStrLn "Failed to load crate"
```

**Example workflow:**
```haskell
ghci> :load Charon.PrintingDebug
ghci> import Charon.Printing
ghci> import qualified Generated_Meta as M
ghci> 
ghci> Just crate <- loadAndPrint "foreign-constant"
Successfully loaded: foreign-constant
ghci> 
ghci> let ctx = emptyCtx { translated = Just crate }
ghci> 
ghci> -- Access specific declarations
ghci> let funs = M.vectorToList $ translatedcrateFunDecls crate
ghci> let firstFun = head funs
ghci> putStrLn $ printWithCtx ctx firstFun
pub fn CONSTANT() -> u8
= <opaque>
```

## Typical Workflow for Debugging

### 1. Identify Discrepancies

```haskell
ghci> compareFile "foreign-constant"
```

Look at the output to see where Haskell and Rust differ.

### 2. Get Detailed Diff

```haskell
ghci> showDiff "foreign-constant"
```

This shows exactly which lines differ.

### 3. Load and Inspect

```haskell
ghci> Just crate <- loadAndPrint "foreign-constant"
ghci> let ctx = emptyCtx { translated = Just crate }
```

Now you can inspect and print specific parts of the AST.

### 4. Test Individual Declarations

```haskell
ghci> import qualified Generated_Meta as M
ghci> let typeDeclsVec = translatedcrateTypeDecls crate
ghci> let typeDecls = M.vectorToList typeDeclsVec
ghci> mapM_ (putStrLn . printWithCtx ctx) typeDecls
```

### 5. Iterate on Fixes

After making changes to `Charon.Printing`, reload:

```haskell
ghci> :reload
ghci> compareFile "foreign-constant"
```

## Test File Locations

- **LLBC files**: `../charon/tests/ui/*.llbc` (generated by Rust tests)
- **Expected output**: `../charon/tests/ui/*.out` (from Rust's `--print-llbc`)
- **Rust source**: `../charon/tests/ui/*.rs`

## Generating LLBC Files

If LLBC files don't exist, you need to generate them:

```bash
cd ../charon
make test
```

This will:
1. Build the charon binary
2. Run all UI tests
3. Generate `.llbc` and `.out` files

## Common Test Files

Some good test files to start with:

- **Simple**: `foreign-constant`, `hide-marker-traits`, `no_nested_borrows`
- **Traits**: `traits`, `traits_special`, `issue-4-traits`
- **Generics**: `params`, `arrays_const_generics`
- **Control flow**: `loops`, `matches`, `ullbc-control-flow`
- **Advanced**: `closures`, `dyn-trait`, `vtables`

## Tips

1. **Start simple**: Begin with `foreign-constant` - it's one of the simplest test cases
2. **Check one declaration type at a time**: Focus on functions, then types, then traits
3. **Use grep**: `grep "DIFF" <(showDiff "test-name")` to see only differences
4. **Compare output length**: If line counts differ significantly, check for missing/extra blank lines
5. **Check indentation**: Rust uses 4-space indentation - make sure Haskell matches

## Troubleshooting

### "LLBC file not found"

Generate the test files:
```bash
cd ../charon
make test
```

### "Failed to decode LLBC file"

The LLBC format may have changed. Check if you need to regenerate:
```bash
cd ../charon
make clean
make test
```

### Import errors in ghci

Make sure to build first:
```bash
stack build
stack ghci
```
